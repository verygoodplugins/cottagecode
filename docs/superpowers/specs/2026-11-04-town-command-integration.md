# Command center in the original town

Approved by the user on 2026-11-04: bring the attention strip, lenses and evidence drawer into the original town, with Dispatch and Threads as toggleable views; retain walking and charm. This is implementation of the approved direction, not a new approval gate. cmux migration is outside this change.

The original canvas renderer remains the Townmap. All houses, resident movement, wildlife, paths, interiors, lighting, sound and music retain their owners. One accepted feed refresh drives every view. A compact brass/paper toolbar and attention strip sit above the scene. Townmap lenses annotate existing plots without changing their layout; an off/default Village lens preserves scenery. Attention, Time, Delivery and Owner reveal one kind of information at a time. Selected/hovered work gets readable context without coating the whole world in text.

Townmap, Dispatch and Threads share the existing inspector as an evidence drawer. Inspector selection is independent of the occupied room: selecting another task in Dispatch does not leave the room or change Jack's location. Switching back returns to the same room/camera. Explicit Locate, Enter, Leave and Follow actions retain their intentional world effects. The inspector exposes full model/harness evidence, distinct wall task age/session age/recorded execution/observation/progress clocks, exact input and source capability, canonical PR receipts, original request, paginated journal, and existing checklist/artifacts. It remains the sole composer, upgraded to the lab's persistent reply/preflight guard. Demo answers remain local.

Dispatch is a compact HTML ledger. Threads draws only recorded issue/task/PR/parent/dependency edges and shared PRs once, with a narrow vertical trace. Both are separate scroll surfaces over a continuously mounted town viewport. Walking and automatic camera-follow are suspended in alternate views; held keys clear on transitions, while clocks/feed/scenery can continue. View keys 1/2/3, Command/Ctrl+K search, J/K list navigation, direct controls and Escape work without taking WASD/E from the canvas or shortcuts from editable fields.

One canonical snapshot joins raw public evidence with normalized town identities. Exact model/status and absent terminal evidence survive normalization; raw PR data cannot override normalized freshness or Hub authority. Missing data remains unavailable. Settled visibility and town filtering agree with the original controls. Source changes clear command data and selections; stale same-source data stays visibly stale. No new polling loop and no new autonomous task writes.

Acceptance: original door walking, E interactions, journals/PR desks, duck startle, music off, night treatment, camera/plot/room stability across view and lens changes, filtering/search/PR preview, shared selection, input safety, stale recovery, public sample network isolation, full Node suite and real browser screenshots. Build a local integrated preview alongside the existing app, not a live runtime migration.
